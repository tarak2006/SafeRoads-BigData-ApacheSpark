⚙️ Apache Spark RDD Processing (Scala)
10 Marks Rubric

Distributed RDD pipeline implementing narrow transformations (map, filter), wide shuffles (reduceByKey, aggregateByKey, join), and actions:

// Ingest raw dataset with 4 partitions val rawRDD = sc.textFile("data/processed/accidents.tsv", 4) // Transformation 1: Filter header & corrupt records val cleanRDD = rawRDD.filter(l => l != header && l.trim.nonEmpty) // Transformation 2: Parse into case class & persist val accidents = cleanRDD.map(parseAccident).persist(StorageLevel.MEMORY_AND_DISK) // Transformation 3 & 4: Key-Value pair reduction & sort val stateCounts = accidents.map(a => (a.state, 1)).reduceByKey(_ + _) val top10 = stateCounts.sortBy(_._2, ascending = false).take(10) // Transformation 5: aggregateByKey for Mean Clearance Delay val stateDelays = accidents.map(a => (a.state, a.durationMinutes)) .aggregateByKey((0.0, 0L))( (acc, v) => (acc._1 + v, acc._2 + 1L), (a1, a2) => (a1._1 + a2._1, a1._2 + a2._2) ).mapValues(acc => acc._1 / acc._2) // Transformation 6: Pair RDD Join val stateJoined = stateCounts.join(stateDelays)
RDD Lineage DAG: Spark constructs execution stages lazily and recomputes lost partitions deterministically from lineage. In-memory caching yielded a 9.3x speedup (180ms vs 1,680ms).
